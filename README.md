# 🏆 Calculadora de Partidas Rankeadas

Desafio de lógica desenvolvido em **JavaScript** que calcula o saldo entre vitórias e derrotas e classifica o nível do jogador.

## 🚀 Tecnologia utilizada

- JavaScript

## ✨ Funcionamento

A função recebe a quantidade de vitórias e derrotas, calcula o saldo e utiliza estruturas condicionais para definir uma classificação.

## 🧠 Conceitos praticados

- Funções
- Variáveis
- Operações matemáticas
- Estruturas condicionais
- Parâmetros e argumentos
- Saída de dados com `console.log()`

## ▶️ Como executar

Com o Node.js instalado, execute:

```bash
node index.js
```

## 📚 Objetivo do projeto

Projeto desenvolvido para praticar funções e lógica de programação por meio de um sistema simples de classificação de partidas.
